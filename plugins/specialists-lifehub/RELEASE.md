# Release v3.5.0

**Date:** 2026-08-05  
**Type:** Minor

The changelog gets three tiers and a release has to earn its bump, and the shared workflow stops assuming it runs in the repo it was written in

This card describes v3.5.0, the version your plugin manifest carries. Whether it is the code you are running is a separate question: the documented update path installs from `main`, so a `main` that has moved past the tag reports this same number. [The version is not the code](https://github.com/DaveKJohn/claude-code-specialists/blob/main/ADOPTION.md#staying-up-to-date) in ADOPTION.md is the check.

No changes to this plugin in this release — see the full notes.
